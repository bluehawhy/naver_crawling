# 프로젝트 및 구현 현황

검토 기준: 기본 브랜치의 트리 `6f067bd7582db3a6b52c6e9c1456cdbed163c091`. 정적 코드 검토이며 실제 네이버 지도 접속이나 실행은 검증하지 않았다.

## 프로젝트 개요

네이버 지도 검색 결과 수집을 시도하는 Python 스크립트 모음이다. README는 네이버 지도 크롤링이라고만 설명하며 상세 요구사항은 없다.

## 구성 및 동작

- `nv_naver_scrap.py`: 검색어를 입력받아 모바일 지도 검색 URL을 열고 HTML에서 이름·전화번호·신주소·구주소를 추출해 콘솔과 `result.txt`에 기록한다.
- `naver_scrap_new.py`: 고정 검색어로 지도 검색 화면을 열고 검색을 시도한다. 상세 정보 추출 및 페이지 이동 코드는 주석 처리되어 있다.
- Selenium, BeautifulSoup, requests를 가져오며 로컬 `./chromedriver`를 지정한다. 의존성 버전 및 실행 환경 명세는 저장소에 없다.

## UI 및 설계

별도의 앱 화면은 확인되지 않는다. 터미널 입력·출력과 Chrome 브라우저를 사용한다. 설계 의도나 화면 명세가 없어 시각적 설계의 적합성은 판단할 수 없다.

## 문서와 구현의 차이 및 확인 사항

- README의 간략한 목적은 코드와 대체로 부합하지만 입력, 출력, 환경, 제약을 설명하지 않는다.
- 새 스크립트의 수집 부분은 주석 처리되어 완성된 수집 기능으로 볼 수 없다. iframe 요소를 순회하면서 `actualRow[0]`을 사용하는 부분의 동작도 실행 확인이 필요하다.
- 모바일 스크립트는 고정된 HTML 클래스와 정규식에 의존하며 페이지 이동은 구현하지 않았다. 현재 네이버 지도 화면과의 호환성은 확인하지 않았다.
- 두 스크립트는 오래된 Selenium 호출 방식을 사용하므로 설치 버전과 브라우저 드라이버 호환성 확인이 필요하다.
- 대기 시간 초과 후에도 `finally`에서 처리를 계속한다. 예외 발생 시 브라우저 종료까지 도달하는지는 보장되지 않는다.

## 문서 관리 지침

기능 변경 시 입력·출력, 의존성 버전, 실행 절차, 지원 범위와 실제 검증 결과를 이 문서에 함께 갱신한다. 확인하지 못한 동작이나 기획 의도는 추정하여 확정하지 않는다.
